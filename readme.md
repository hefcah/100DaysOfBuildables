# ML Model Deployment with Streamlit

This project fine-tunes a machine learning model using cross-validation and hyperparameter tuning, then deploys it as an interactive Streamlit web app.

## Features
- Tuned Random Forest model
- Real-time predictions
- User-friendly interface
- Deployable on Streamlit Cloud
